## Adaptaciones y fallos encontrados

- ASG vacío recuperado reafirmando capacidad deseada; la actividad antigua mostraba lanzamientos cancelados, sin causa final demostrada (INC-016).
- AWS Academy denegó `StartInstanceRefresh` por SCP; se retiró esa función opcional sin cambiar IAM/SCP (INC-018).
- La prueba CPU no sostuvo el umbral por agotamiento de créditos T3 Standard. No se activó Unlimited; el escalado exitoso se probó con solicitudes reales y un umbral académico de 30 por target/minuto (INC-019).
- SSH local GCP tuvo timeout; administración restringida desde gateway AWS por SSM. Acceso independiente mediante consola/IAP no validado (INC-020).
- Se corrigieron el intérprete Bash para SSM y la diferencia de socket PostgreSQL entre distribuciones (INC-021/022).
- El primer reencendido devolvió IP GCP vacía y retiró reglas UDP en AWS. Se exige IP válida y CHILD_SA instalada, se recuperó el túnel y se reejecutó el flujo completo. No se presenta el primer intento como exitoso (INC-023).
- La IP GCP nueva recibió 403 del filtro FortiGuard local, categoría Unrated. El servicio respondió 200 desde AWS; el acceso desde esa red local sigue pendiente de su política. No se modificó el filtro (INC-024).
- Tras devolver GCP a standby, una repetición de restauración fue rechazada por solo lectura. Se conservó su rol y se verificaron las copias finales en BDs temporales AWS; la restauración previa en GCP primario permanece acreditada (INC-025).

Detalles y fechas en [incidencias/REGISTRO.md](../../incidencias/REGISTRO.md). ## Límites y siguientes pasos

1. **Continuidad manual:** el script solicita la promoción y cambia conexiones; el portal alternativo usa otra URL. No hay detector/promotor autónomo ni failover DNS automático. Se detuvieron procesos AWS, no el proveedor ni su plano de administración. La administración GCP todavía depende del gateway AWS.
2. **Disponibilidad por sesión:** al apagar se conservan datos, pero se interrumpen portal y réplica. La BD de una sola zona y el gateway/NAT siguen siendo puntos únicos de falla. No se demuestra servicio permanente ni capacidad para miles de usuarios.
3. **Créditos:** presupuesto GCP declarado US$10/mes; saldo y vencimiento no verificados, Cloud Billing API deshabilitada. Los costos consultados en AWS/Azure no son saldo y pueden incluir otras cargas. IPv4, tráfico, almacenamiento y operaciones pueden consumir crédito; no se garantiza costo cero.
4. **Documentos por unidad:** V1 y V2 conservan entregables separados. Los textos INFORME no se modificaron en esta ejecución; hay que alinear la redacción académica con estas pruebas, completar integrantes/docente/equipo y mantener los espacios de capturas. Las [capturas automatizadas del portal](../../integracion/evidencias/20261104/capturas-automatizadas.json) son complementarias.
5. **Pendientes externos:** comprobar saldos/vencimientos en consola, resolver el acceso local a la URL GCP conforme a la política de red y validar el monitoreo ampliado GCP y definir un destino si se desean notificaciones. No se enviaron mensajes externos.

Para preparar otra sesión: renovar las credenciales Academy si caducaron y ejecutar `./nexoandes continuidad`. Para cerrar: `./nexoandes apagar`. Procedimiento y recuperación de interrupciones en [integracion/CONTINUIDAD.md](../../integracion/CONTINUIDAD.md).
