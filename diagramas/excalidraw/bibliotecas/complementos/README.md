# Símbolos complementarios

Iconos de Lucide y logotipos Supabase/PostgreSQL de Simple Icons descargados de sus repositorios primarios, con commits fijados. URLs, SHA256, autoría y licencia por archivo están en `FUENTES.json`. Licencias completas: `LICENSE-Lucide` y `LICENSE-Simple-Icons`.

Lucide se utiliza para conceptos genéricos: Security Groups, privacidad, autenticación, REST, conectividad, paneles, metadatos, portal, discos, pausa, versionado y retención. Estos símbolos no implican nuevos productos cloud desplegados. El escudo de Security Groups no es el icono de AWS Shield.

Se conservan los originales. El generador colorea `currentColor` para representar los controles y aplica el color de marca a los logotipos monocromos antes de incrustarlos. Son objetos SVG individuales dentro del Excalidraw.
